# MEMORIA

> Este archivo tiene DOS propósitos únicos y exclusivos. Toda escritura aquí requiere
> aceptación explícita del usuario antes de guardarse.

## 1) Aprendizajes de errores
Cuando se comete un error (build roto, mala ubicación de una clase, decisión incorrecta),
se anota aquí la lección para no repetirla. Formato:

- **[fecha] Error:** qué pasó. **Causa:** por qué. **Corrección:** qué hacer en adelante.

## 2) Resúmenes de sesión
Al final de una sesión, cuando el usuario lo pida, se guarda aquí un resumen de lo más
importante (decisiones, estructura creada, pendientes). Formato:

- **[fecha] Sesión:** resumen breve de lo realizado y lo que queda pendiente.
